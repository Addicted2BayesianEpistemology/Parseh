#
# Python 3.12 only (the wheels are cp312).  Every requirement carries the SHA-256 of
# every wheel that can be taken on the five computers Parseh installs on (linux x86_64,
# linux aarch64, macOS arm64, macOS x86_64, Windows amd64); pip takes the one its
# computer can use and refuses any file whose hash is not listed, so what is installed
# is fixed by this list and by nothing PyPI answers later.  The markers select ONE
# set per computer: hf-xet and colorama are wanted only where they exist, and an
# Intel Mac takes onnxruntime 1.23.2 (nothing newer is built for it) with the four
# packages that version needs.  No NVIDIA library is in it, on purpose: the graphics
# card's own software is the computer's, never Parseh's to install.
#
# It is the whole closure, complete because pip's hash-checking mode refuses any
# package that is not listed.  Moving a pin means moving lib/getstt.py PIN and MEASURED
# with it, and the generation there: tests/test_getstt.py holds the three together.
# Installed by:  python -m pip install --require-hashes --no-deps --only-binary=:all:
#                --target <stt/runtime.part-...> -r lib/stt-requirements.txt
