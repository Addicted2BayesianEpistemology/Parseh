## ASR slips these four videos make constantly

The speech is clear; the auto-transcript is not. Leave `fa` wrong, put
the truth in `note`. The recurring ones:

- **شاهیداس / شاهمیداس / شاه می‌داس / شاهیداز / شاه میداز / شاه میداست**
  — all one thing: `شاه میداس šāh Midās` "King Midas", run together by
  the transcriber. Note it the first few times, then let it be.
- **می‌فندد** = می‌خندد *mi-xandad*; **ورنده** = برنده *barande*;
  **خشمین** = خشمگین; **می‌گشت** = می‌کُشد *mi-košad* (he kills);
  **گوش‌های خرید** = گوش‌های خری; **سازیپ** = ساز پایپ;
  **استا** = است; **س مرغ** = سه مرغ; **زیمرغ / سیورب** = سیمرغ;
  **هد** = هدهد; **پسفر** = پس سفر; **سیم مرغ** = سی مرغ.
- Bracketed sounds — `[خنده]` laughter, `[صدای آه]` a sigh,
  `[صدای بند آمدن نفس]` a gasp, `[صدای خرناس]` a snort/snore,
  `[موسیقی]` music, `[گلویش را صاف می‌کند]` clearing the throat — are
  their own chunk: `fa` the bracketed text, `tr` a romanised echo, `en`
  the sound in English. No `voc`.
