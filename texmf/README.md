# texmf/

The TeX packages Parseh got for the LaTeX drawings, from **Settings →
LaTeX drawings** (lib/texpackages.py): a TeX tree of Parseh's own, filled by
tlmgr in its user mode, and the list of what is in it,
`parseh-packages.json`.  Every drawing is pointed at it; nothing else of the
computer's TeX is touched.  It is yours: an update keeps it, as it keeps
`dict/` and the rest.
